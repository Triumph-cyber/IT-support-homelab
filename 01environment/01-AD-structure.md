# Active Directory Structure

## Organization

The lab simulates the IT environment of Triumph Technologies,
a fictional organization with five departments:

- IT
- HR
- Finance
- Sales
- Operations

## Organizational Units

The following OUs were created:

- IT
- HR
- Finance
- Sales
- Operations
- Computers
  - Workstations
- Groups

## Security Groups

The following Global Security Groups were created:

- GG-IT-Users
- GG-HR-Users
- GG-Finance-Users
- GG-Sales-Users
- GG-Operations-Users

## User Accounts

Ten fictional employee accounts were created and assigned
to their respective departmental OUs and security groups.

## Purpose

The OU structure provides an organizational framework for
managing users and computers. Security groups will later be
used to control access to shared resources and applications.
